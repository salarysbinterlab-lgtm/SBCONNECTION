# ผมยืนยันแทนไม่ได้ 3 ข้อ

1. **ข้อ 4–5 (บัตรพลิกบน iPhone)** ไม่มีเครื่องจริงทดสอบ แก้ตามสาเหตุที่วิเคราะห์จากภาพหน้าจอ

2. **ตัวเลขทุกตัวในช่วง A** ต้องมาจากการรันจริงบน Supabase ของคุณ
3. **`npm run check`** รันจากที่นี่ไม่ได้ (npm ถูกบล็อก) — `push.bat` จะรันให้เองในขั้น [3/7]

**ที่ตรวจแล้วจริง** กติกาบรรทัดตำแหน่ง 7 เคสผ่านหมด · ชิ้นส่วนปฏิทินครบทั้ง 6 จุด ·

`30_` `31_` `32_` รันจริงแบบมีบัญชี `ADMIN` `DEV` อยู่ในฐาน ผ่านทั้ง 3 ไฟล์
